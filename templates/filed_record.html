How to check these files

Don't take my word for any of this. Everything you need to check it yourself is in the pack, alongside the file manifest.sha256. Put them in one folder and run:

sha256sum -c manifest.sha256

That single command is the same integrity check most carriers' own claims tools already run. OK against a file means it still matches what my device recorded when this pack was built; anything else means don't trust that one file without asking me about it first. manifest.sha256 holds one line per file — a 64 character digest, two spaces, the file name — which is the exact layout sha256sum requires, nothing specific to this claim.

These digests were computed by Doorstep Receipt over files Doorstep Receipt also wrote. They show whether a file has changed since {{prepared}}. They do not establish who assembled this pack and they do not establish that what it says is accurate.
